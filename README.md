SOSCleaner
==========

[![CI](https://github.com/jduncan-rva/soscleaner/actions/workflows/ci.yml/badge.svg)](https://github.com/jduncan-rva/soscleaner/actions/workflows/ci.yml) [![Coverage Status](https://coveralls.io/repos/github/jduncan-rva/soscleaner/badge.svg?branch=master)](https://coveralls.io/github/jduncan-rva/soscleaner?branch=master) [![PyPI version](https://badge.fury.io/py/soscleaner.svg)](https://badge.fury.io/py/soscleaner)


Purpose
-------
SOSCleaner is a tool to consistently obfuscate sensitive information in large datasets like Red Hat sosreports. It works on any data set, from 1 file to thousands.

Requirements
------------
- **Python 3.8+** (Python 3.8, 3.9, 3.10, 3.11, 3.12 supported)
- No external dependencies (uses Python stdlib only)

> **Note:** Python 2 users should use version 0.4.x. Version 0.5.0+ requires Python 3.8 or later.
